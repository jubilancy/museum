About Museum

Museum is a static, dependency-free gallery of public domain artwork. There is no database and no server — every page reads directly from a single artworks.csv file checked into this repository, parsed in the browser with plain JavaScript.

How it works

Each row in artworks.csv describes one artwork: its image URL, title, source institution and a comma-separated list of tags. The gallery, sources index and tag index are all built from that one file — add a row, push, and the site updates.

Keeping the tag index fresh

A GitHub Actions workflow runs on every push: it reads artworks.csv, regenerates tags-data.json, and deploys the result to GitHub Pages. New tags on new artwork show up on the Tags page automatically, with no manual bookkeeping.

Adding artwork

Open artworks.csv, add a row with an image URL, title, source and tags, and push to the main branch. No build tools or dependencies are required to run or extend this site.
